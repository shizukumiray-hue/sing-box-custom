║                           PLACEHOLDER SYNTAX                              ║
╠═══════════════════════════════════════════════════════════════════════════╣
║  [crlf]   → \r\n               Carriage Return + Line Feed               ║
║  [lf]     → \n                 Line Feed only                            ║
║  [cr]     → \r                 Carriage Return only                      ║
║  [split]  → Packet Split       Send packet, wait 100ms, continue         ║
║  [host]   → Real Server        Your actual SSH server hostname/IP        ║
║  [port]   → Real Port          Your actual SSH server port               ║
║  [proxy]  → Bug Host           SNI/Host for spoofing (from bug_host)     ║
║  [ua]     → User-Agent         Browser User-Agent string                 ║

╔═══════════════════════════════════════════════════════════════════════════╗
║                            TIPS & TRICKS                                  ║
╚═══════════════════════════════════════════════════════════════════════════╝

1. Test payload di browser/curl dulu sebelum pakai di sing-box
2. Gunakan [split] untuk operator dengan DPI ketat
3. Bug host harus support HTTPS untuk bypass DPI
4. Jangan gunakan custom_payload jika tidak perlu (overhead)
5. Simpan backup payload yang bekerja untuk masing-masing operator
6. Update bug host secara berkala (kadang provider block)
