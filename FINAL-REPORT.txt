ARCHITECTURE:
Config → Options → Client → dialContext() → Custom Payload Mode
                                          └→ Standard WS Mode (fallback)

KEY FUNCTIONS:
1. ParseCustomPayload()     - Parse template & replace placeholders
2. SendCustomPayload()      - Send payload dengan packet splitting
3. BuildDefaultUserAgent()  - Default User-Agent generator
4. dialContext()            - Modified untuk support custom payload

LOGIC FLOW:
1. Load config (custom_payload, bug_host)
2. Initialize Client dengan payload data
3. On connection:
   ├─ If custom_payload empty → Standard WS handshake
   └─ If custom_payload set:
      ├─ Parse placeholders
      ├─ Split by [split] marker
      ├─ Send each part dengan delay
      └─ Return raw WebSocket connection
